# Remotion Cube Presentation

The Cube Transition template provides a presentation that can be used inside `<TransitionSeries.Transition>` component from the `@remotion/transitions` package, to create a 3D cube transition.

Control the cube rotation and the perspective on the cube via direction and perspective properties of the cube API.

Customize the presentation to your liking by directly manipulating the provided source code.

## Where to get it

You can purchase this template on [remotion.pro/cube-transition]("https://www.remotion.pro/cube-transition"). You then directly access the source code on github or install the package via npm.
